HTML Introduction

  • HTML stands for HyperText Markup Language.
  • HTML is used to create web pages.
  • HTML uses tags to define elements.
  • Browsers render HTML pages.
  • HTML works with CSS and JavaScript.

HTML Basic

Example

<h1>Hello World</h1>
<p>My First HTML Page</p>

HTML Elements

  • Everything in HTML is an element.
  • Elements have opening and closing tags.
  • Some tags are self-closing.
  • Elements can contain content.
  • Elements can contain other elements.

HTML Attributes

  • Attributes provide extra information.
  • Attributes are written inside start tags.
  • href, src and alt are common attributes.
  • Attributes usually have values.
  • Example: href="page.html"
